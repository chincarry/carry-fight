# 陈锴瑞 VS 陈锴瑞 · 八相乱斗

一个致敬《死神 VS 火影》的 **2D 横版格斗游戏**，纯原生实现：HTML5 Canvas 2D + 原生 JavaScript + CSS。
**零框架、零构建、零 npm 依赖、零外部网络资源**，离线可玩；单机对战与 **P2P 在线联机**双模式。

## 如何运行

- **最简单**：直接双击 `index.html`（file:// 协议即可运行，未使用 ES Module）。
- 或用本地静态服务器（推荐，避免个别浏览器对本地文件的限制）：

```bash
cd 项目根目录
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

- 首次按键/点击后才会启用音效（浏览器自动播放策略），按 `M` 静音，按 `F` 全屏。
- 逻辑分辨率固定 1280×720，窗口会等比缩放保持 16:9。

## 键位

| 操作 | 1P（左） | 2P（右） |
|---|---|---|
| 移动 | `A` / `D` | `←` / `→` |
| 跳跃 | `W`（天使可二段跳） | `↑` |
| 防御 | `S`（按住原地防御）或 后方向（后退走位时仍算防御） | `↓`（按住原地防御）或 后方向（后退走位时仍算防御） |
| 轻攻 | `J`（可三连 J-J-J） | `1`（主键盘 / 小键盘均可） |
| 重攻 | `K` | `2` |
| **上挑** | `W` + `J`（起跳即挑），或起跳上升中按 `J` | `↑` + `1`，或上升中按 `1` |
| **下落斩** | 空中下落时按 `K` | 空中下落时按 `2` |
| 技能（25 气） | `L` | `3` |
| 必杀（100 气） | `U` | `4` |
| 冲刺 / 闪避 | `Shift` | `0` |
| **援助召唤** | `E`（每场 3 次） | `5`（每场 3 次） |

菜单：`↑`/`↓` 选择，`Enter` 确定；选人页 `R` 随机，`Esc` 返回。全部菜单也支持鼠标点击。

**系统规则**：每局 HP 1000、气 0–100（自然回气 8/s，命中与受击额外回气）；3 局 2 胜；每局 99 秒，时间到血多者胜。
格挡减伤 80% 且无硬直；受击前 6 帧内进入防御 = **完美格挡**（额外回气 15 + 白闪）。连击 ≥2 显示 `N HIT`（记在攻击方那半边），1.2 秒无命中清除。
出招硬直中按下的技能/必杀会进入 10 帧输入缓冲，可行动帧到来时自动出手；平局不计胜场（可能打到双方 1:1 的决胜局）。

### 援助系统

选人页选完角色后会进入**援助选择**（6 选 1，`Esc` 可退回重选角色），战斗中按 `E`（2P 为 `5`）召唤。
每场（3 小局）共 **3 次**，两次召唤间隔 0.75 秒冷却；召援动作（约 0.37 秒）中被击中则援助作废、**次数不退还**。
援助无敌、不参与碰撞，出现约 1 秒后自动退场；对手处于冻结时被任意攻击命中会立刻解冻。

| 援助 | 招式 | 效果 |
|---|---|---|
| 侦探于沛頎 | 秒表 · 时停 | 对手定格 45 帧（0.75 秒）并受 50 伤 |
| 仙人杨子一 | 青蝶 · 回春 | 自己回 200 血 + 20 气，同时蝶影撞伤对手 45 |
| 黑道孙啸晨 | 黑道 · 清算 | 三连击各 52（合计 156），末段击飞 |
| 肌霸郭亚祥 | 钢铁 · 冲撞 | 单发 120，破 Lv2 霸体、不可防御、大击退 |
| 探险肖牧辰 | 索钩 · 拖拽 | 把对手拽到面前（80 伤 + 34 帧硬直），直接接连段 |
| 法师陆景西 | 星陨术 | 对手头顶落星，170 伤、不可防御 |

街机模式 AI 也会随机携带援助并在残血 / 远距离时择机召唤；联机模式下召唤事件与剩余次数由主机权威同步。

### 空中攻防三角

| 招式 | 伤害 / 判定 | 特点 | 代价 |
|---|---|---|---|
| **下落斩**（空中下落按重攻） | 128，160×146 大判定 | **不可防御**（格挡照样吃满）、落地冲击波、可破 Lv2 及以下霸体 | 被上挑命中即被击飞并陷入 30 帧僵直 |
| **上挑**（起跳时按轻攻） | 74，96×128 上抬判定 | 命中击飞 700（可直接接空中追击） | 起手 8 帧无霸体，**会被任何普通攻击打断** |
| **普通攻击** | 34~88 | 出手最快 | 打不过下落斩（会被破防） |

三者构成石头剪刀布：**下落斩 ＞ 格挡 ＞ …／上挑 ＞ 下落斩 ＞ 普攻 ＞ 上挑**。
结算顺序保证了同一帧对拼时上挑必胜：`game.js` 的 `resolveHits()` 跑两趟，先结算上挑，被打飞的一方出招当场取消。

### 霸体（分级）

霸体期间**照常吃伤害**，但不会进入硬直、不会被打断出招（血条上方会弹 `ARMOR`）。

| 等级 | 归属 | 说明 |
|---|---|---|
| Lv3 | 拳击陈锴瑞（必杀） | 最高优先，任何招式都破不掉；对拼时压制 Lv2 |
| Lv2 | 恶龙陈锴瑞（必杀） | 普攻/技能打不断，但会被下落斩（armorBreak=2）破甲 |
| Lv1 | — | 预留档位 |
| Lv0 | 其余 6 名角色 | 必杀**没有霸体**，全过程可被打断 |

其余 6 个角色（般若 / 天使 / 舞女 / 术士 / 游侠 / 浪人）的必杀原本是 110~180 帧完全无敌，
现已全部改为可被打断——放必杀要看时机和距离，不能无脑贴脸按。

## 在线联机（P2P）

标题页 → **联机对战**。双方打开同一个网址，一方「创建房间」拿到 6 位联机码，
另一方「加入房间」输入同一联机码，即可对战。**不需要服务器、不需要注册、不需要数据库。**

- **昵称**：标题页「昵称设置」可改（存 localStorage，最长 12 字）。昵称会替代角色名显示在
  HUD 主标题、VS 画面与结算页，角色名作为副行保留。
- **架构**：WebRTC P2P 直连（`RTCPeerConnection` + DataChannel），信令走 PeerJS 公共云
  （`0.peerjs.com`，仅交换 SDP，不传输任何对局数据）。技术上完全没有中转服务器，
  延迟就是两端之间的真实网络 RTT。
- **同步模型**：**主机权威**。主机跑全部战斗模拟，客机只上传输入（60Hz 位掩码）、
  下载快照（30Hz）。技能特效实体是闭包创建的、无法序列化，因此改成"事件广播 +
  两端各自本地生成特效"，命中判定仍只在主机侧结算，不会出现双端血量不一致。
- **容错**：1s 心跳 + 5 采样 RTT 均值，3s 无包判定掉线并冻结画面提示；15s 未连通报超时。
  联机码占用（`unavailable-id`）、码不存在（`peer-unavailable`）都有中文提示。
- **NAT 穿透**：默认 3 个公共 STUN（Google ×2 + Cloudflare）。约 85%~90% 的家庭宽带可直连；
  遇到对称型 NAT / 部分企业网需要 TURN 中继，见 `server/` 目录与 `部署指南.md`。
  自检方法：控制台执行 `BVN.Net.diag()`，看 `candidates.relay` 是否 > 0。

## AI 难度

标题页「难度选择」可切换：**简单**（反应 300ms，少用技能）/ **普通**（150ms，会用技能）/ **困难**（60ms，会格挡、会接必杀、会跳躲飞行道具）。

## 文件结构

```
index.html            入口：canvas + 按顺序引入 13 个传统 script（非 ES Module）
css/style.css         页面底板、16:9 等比缩放、联机输入框样式
js/vendor/peerjs.min.js  PeerJS 1.5.4（本地打包，不依赖 CDN）
js/net-config.js      联机配置：信令地址 / ICE 服务器 / TURN、联机码字符集、心跳参数
js/net.js             传输层：建房、加入、收发、心跳 RTT、错误文案翻译、NAT 自检
js/netplay.js         联机流程：大厅状态机、昵称存取、输入采集、快照编解码、联机选人
js/data.js            全局常量、角色数据表、招式帧数据（新增角色只需在此加一条）
js/audio.js           WebAudio 程序化合成音效（无音频文件）
js/effects.js         粒子 / 命中火花 / 伤害数字 / 刀光弧线 / 冲击环
js/art.js             程序化矢量骨骼角色绘制 + 场景背景
js/skills.js          八角色技能/必杀实现 + 投射物与场地实体
js/fighter.js         Fighter 类：状态机、物理、判定盒、受击硬直/击倒、姿势驱动
js/ai.js              AI 控制器（三档难度）
js/game.js            场景状态机（标题→选人→VS→战斗→结算 / 联机大厅）、主循环、相机、HUD
tools/build-single.js 零依赖打包脚本：把 CSS + 14 个 JS + 14 张立绘 base64 内联成单文件
server/               可选：coturn TURN 中继配置模板（仅对称 NAT 环境需要）
部署指南.md            上传部署 + 买服务器 + 联机排查的完整步骤
dist/index.html       打包产物：单文件约 3MB，直接丢到网站根目录即可
```

**扩展方式**：在 `js/data.js` 的 `ROSTER` 追加一条角色数据（配色 / 数值 / 技能文案），
在 `js/skills.js` 的 `IMPL` 与 `SKILL_ATTACKS` 中补上对应技能实现与帧数据，
在 `js/art.js` 的 `FEATURES` 中补一个特征件绘制函数即可；战斗逻辑无需改动，联机自动兼容。

## 打包与部署

```bash
node tools/build-single.js      # 产出 dist/index.html（CSS/JS/图片全内联，约 2.7MB）
```

只有一个文件，把它覆盖到网站根目录就完成更新，不用管静态资源的相对路径。
详见 `部署指南.md`。

## 技术要点

- 固定步长主循环（`dt = 1/60` 累加器，最多补 5 帧），渲染与逻辑分离，慢动作通过缩小累加器步进实现。
- 角色本体全部程序化矢量绘制（分层骨骼 + 姿势插值 lerp 0.26/0.42），非贴图精灵；立绘仅用于选人卡片、HUD 头像、VS 画面与结算特写。
- 立绘裁切：8 张原图宽高比差异极大（0.56~1.78，横竖混杂），因此在 `ROSTER` 里为每张图单独标了归一化人脸锚点 `face: [fx, fy]`，`Art.drawCover` 以该点为中心取裁切窗口并夹紧到源图范围，保证任何卡片/头像比例下都切不到脸。新增角色时补一个 `face` 即可。
- 命中反馈：受击闪白 3 帧 + 屏幕震动（伤害加权）+ 顿帧（hitstop）+ 火花粒子 + 飘伤害数字。
- 相机：以双方中点为焦点，按距离在 1.0–1.2 之间缩放并夹紧边界，永不露底。
- 联机输入用 9 位位掩码压缩（左/右/上/下/轻/重/技能/必杀/冲刺），快照只有 20 个数值字段，
  单包约 300 字节；客机对「自己那一侧」做 0.5 系数渐进纠偏（阈值 12px，超过 80px 直接吸附），
  实测残差 7px 以内，观感无跳变。
