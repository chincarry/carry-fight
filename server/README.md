# server/ —— 可选：TURN 中继服务器配置

**只有当你决定购买服务器时才需要这个目录。**

游戏联机默认走 WebRTC 点对点直连，**不需要任何服务器**。
但有约 10~20% 的网络（对称型 NAT，常见于移动网络、部分校园网/企业网）无法直连，
此时需要一台带公网 IP 的机器做 TURN 中继，把游戏数据转发一下。

- 配置模板：`turnserver.conf`
- 完整部署步骤（安装 / 开放端口 / 填入参数 / 生成部署包）：见项目根目录 `../部署指南.md` 第五节
- 建议规格：1 核 1G 足够（中继只转发几十 KB/s 的小包），关键看**带宽**和**离玩家的距离**
- 建议机房：中国香港 / 新加坡（离大陆近，且免 ICP 备案）

接入后如何确认生效：对局中打开浏览器控制台执行 `BVN.Net.diag()`，
看到 `candidates.relay` 大于 0 即表示中继已启用并被使用。
